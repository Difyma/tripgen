# Project Summary
The project is a travel planning application that allows users to create personalized itineraries by connecting with travel creators and local experts. It focuses on providing unique travel experiences, leveraging AI technology for itinerary generation and offering a platform for creators to share their expertise.

# Project Module Description
- **Chat Module**: Handles user interactions, providing a chat interface for planning trips.
- **Creator Module**: Allows users to apply to become travel creators and showcase their profiles.
- **Search Module**: Enables users to search for destinations and plan trips based on preferences.
- **Booking Module**: Integrates with external APIs to fetch flight and accommodation information.

# File Description Inventory
- **src/components/Chat.tsx**: Main chat interface for interacting with the AI.
- **src/components/CreatorForm.tsx**: Form for users to submit applications to become creators.
- **src/components/Hero.tsx**: Landing page hero section with search functionality.
- **src/components/CreatorPage.tsx**: Displays a list of travel creators and their profiles.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **State Management**: Context API
- **API**: OpenAI API for chat responses, Ostrovok API for hotel bookings
- **Build Tools**: Vite, ESLint, Prettier

# Usage
1. **Install Dependencies**: Use `pnpm install` to install all project dependencies.
2. **Build Project**: Run `pnpm run build` to compile the project.
3. **Run Development Server**: Use `pnpm run dev` to start the development server.
