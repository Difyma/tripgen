# Реализация истории чатов (Chat History)

## Описание

Реализована функциональность сохранения нескольких чатов на пользователя (ChatGPT-style).

## Архитектура

### База данных (Supabase)

Созданы две новые таблицы:

#### 1. `chats` - таблица чатов (метаданные)
- `id` (UUID) - уникальный идентификатор чата
- `user_id` (UUID) - ID пользователя (ссылка на auth.users)
- `title` (TEXT) - название чата (генерируется из первого сообщения)
- `created_at` (TIMESTAMPTZ) - дата создания
- `updated_at` (TIMESTAMPTZ) - дата последнего обновления

#### 2. `chat_messages` - таблица сообщений
- `id` (UUID) - уникальный идентификатор сообщения
- `chat_id` (UUID) - ID чата (ссылка на chats)
- `role` (TEXT) - роль отправителя ('user', 'assistant', 'system')
- `content` (TEXT) - содержимое сообщения
- `created_at` (TIMESTAMPTZ) - дата создания

### Безопасность (RLS)

Настроены Row Level Security политики:
- Пользователи могут видеть/создавать/редактировать/удалять только свои чаты
- Пользователи могут работать только с сообщениями из своих чатов

### Новые функции:


## UI компоненты

### Sidebar.tsx
- Загрузка списка чатов при входе пользователя
- Отображение чатов с датой последнего обновления
- Кнопка "Новый чат" для создания чистого чата
- Кнопка удаления чата (при наведении)
- Обновление списка при открытии раздела "Чаты"

### Chat.tsx
- Загрузка конкретного чата из URL параметра (`?chat=uuid`)
- Автоматическое создание нового чата при первом сообщении
- Сохранение всех сообщений в базу данных
- Сброс состояния при переходе на /chat без параметров

## Поток работы

1. **Пользователь открывает /chat:**
   - Отображается чистый чат с приветственным сообщением
   - currentChatId = null

2. **Пользователь отправляет первое сообщение:**
   - Создаётся новый чат в базе данных
   - Генерируется название из первых 30 символов сообщения
   - Сообщение пользователя сохраняется в чат
   - Приветственное сообщение также сохраняется

3. **AI отвечает:**
   - Ответ сохраняется в тот же чат
   - updated_at чата обновляется

4. **Пользователь возвращается позже:**
   - В sidebar отображается список всех чатов
   - При клике на чат происходит загрузка всех сообщений

5. **Создание нового чата:**
   - Кнопка "Новый чат" в sidebar ведёт на /chat
   - Или можно просто начать писать в чистом чате
